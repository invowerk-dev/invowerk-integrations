# Privacy policy

This plugin sends the inputs you pass to its tools (files, text and parameters) to the invowerk API at https://api.invowerk.dev over HTTPS, together with your API key, to run the operation you call, and returns the API's answer to Dify.

The plugin itself does not collect, store or log any data, and it sends nothing to any other third party.

invowerk processes the data it receives under its own privacy policy: https://invowerk.dev/privacy
